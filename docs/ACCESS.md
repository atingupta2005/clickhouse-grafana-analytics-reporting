## Data used in labs

| Item | Value |
|------|-------|
| Database | `training` |
| Reporting view | `training.v_lab_orders` |
| Status in queries | `Completed` |
| Completed regions | 1, 3, 5 |
| Date range | 2023-01-01 … 2025-06-18 |

In Grafana, use an **absolute** time range for that date window when panels look empty.
