# Session 12 — Advanced Grafana Dashboards

**Duration:** 3 hours

## Overview

Improve dashboard layout, panel types, thresholds, transformations, and navigation for clearer reporting.

![Dashboard reading order](./assets/dashboard-reading-order.svg)

## Topics

* Layout and panel purpose
* Stats, trends, tables, thresholds
* Transformations and calculated values
* Links / drill-down
* Performance habits (LIMIT, absolute time, Completed regions)

## Hands-on

* Sign in (`student` / `StudentLab!2026`)
* Reuse Session 10 variable patterns on ClickHouse panels
* Build a polished multi-panel dashboard

**Core:** layout → 3+ panel types → thresholds → one transformation → save 

**Stretch:** annotations, Infinity panel, extra drill-down

**Seed:** Completed regions **1 / 3 / 5**; dates **2023-01-01** … **2025-06-18**
